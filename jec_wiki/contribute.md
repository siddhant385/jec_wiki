

## What can you contribute?

### 📚 Academic resources
- Syllabus, schemes and academic calendars
- Previous-year question papers and study resources
- Official notices and result links
- Corrections to outdated academic information

### 🎓 College and student life
- Admission and college essentials
- Hostel and campus facility information
- Clubs, societies, events and coding communities
- Practical guides and frequently asked questions

### ✍️ Improvements to existing pages
- Correct spelling and factual errors
- Fix broken links
- Improve explanations and page organization
- Update outdated information with a reliable source

## How to contribute

### Option 1: Report an issue

**Best for beginners — no coding required.**

1. Visit the [GitHub Issues page](https://github.com/siddhant385/jec_wiki/issues).
2. Describe the missing information, error or improvement you suggest.
3. Include the relevant page link and a source, if available.
4. Submit the issue so contributors can review it.

### Option 2: Edit a page and submit a pull request

**Best if you're comfortable editing Markdown and using GitHub.**

1. Open the [JEC Wiki repository](https://github.com/siddhant385/jec_wiki).
2. Fork the repository and clone your fork, or edit a file using GitHub's web editor.
3. Make your changes in the relevant Markdown file.
4. Preview the page and check that links work.
5. Submit a pull request explaining what you changed and why.

## Guidelines for good contributions

- **Be accurate:** Prefer official college sources for academic information.
- **Add sources:** Include official links or references for factual claims wherever possible.
- **Keep it useful:** Write clearly so students from any semester can understand.
- **Avoid duplication:** Check whether the information already exists before creating a new page.
- **Respect privacy:** Never publish personal phone numbers, private conversations, student credentials or other sensitive information without permission.
- **Be transparent:** If something is unverified, label it as such instead of presenting it as confirmed.

## Before submitting

If you've changed Markdown files locally, run the production build to check for broken links and other build errors:

```bash
pnpm run docs:build
```

Resolve any errors before submitting your pull request.
